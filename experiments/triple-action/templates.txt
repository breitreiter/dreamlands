# triple-action encounter templates
# format:
#   === <id> | <display name>
#   monster: <name> <hp>
#     <move>            (one move per line, indentation optional)
#     <move>
#     ...
#   player: <name> <hp>
#     <move>
#     ...
# blank lines and lines starting with # are ignored.
# moves are space-separated keywords; the last keyword is the base action.
# valid bases: attack, defend, recover, read
# valid mutators: see project/design/super_rps.md
